      Public APIs, no key needed.

      The same endpoints the extensions use. CORS is open, so you can call them from any page.

      GET words.url2.at/api/words

      A random dictionary word with its meanings.

      curl https://words.url2.at/api/words
      {
  "_id": "ephemeral",
  "meanings": [{
    "definition": "Lasting for a very short time.",
    "speech_part": "adjective",
    "example": "Fashion is ephemeral; style is eternal."
  }]
}
      POST url2.at/api/tinyurl

      Shorten a link. Add a Bearer token to own it in your dashboard.

      curl -X POST https://url2.at/api/tinyurl \
  -H "Content-Type: application/json" \
  -d '{"longUrl":"https://example.com/a/very/long/path"}'
      {
  "code": "abc12",
  "longUrl": "https://example.com/a/very/long/path",
  "tinyUrl": "https://url2.at/abc12"
}
