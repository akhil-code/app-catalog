Public APIs

Call them from anywhere. No key needed.

The same endpoints the extensions use. CORS is open, so any page can call them.

Request
curl https://words.url2.at/api/words
Response · 200
{
  "_id": "ephemeral",
  "meanings": [{
    "definition": "Lasting for a very short time.",
    "speech_part": "adjective",
    "example": "Fashion is ephemeral; style is eternal."
  }]
}
Request
curl -X POST https://url2.at/api/tinyurl \
  -H "Content-Type: application/json" \
  -d '{"longUrl":"https://example.com/a/very/long/path"}'
Response · 201
{
  "code": "abc12",
  "longUrl": "https://example.com/a/very/long/path",
  "tinyUrl": "https://url2.at/abc12"
}
